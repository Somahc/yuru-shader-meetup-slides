# yuru-shader-meetup-slides

シェーダー交流会用のSlidevプロジェクト。スライド本文は未作成です。

## 起動

```sh
npm install
npm run dev
```

`slides.md`を編集してスライドを作成します。

## ビルド

```sh
npm run build
```

## PDF出力

初回のみ、出力に使うブラウザーをインストールします。

```sh
npm install -D playwright-chromium
npm run export
```

[Slidev公式ガイド](https://sli.dev/guide/)
